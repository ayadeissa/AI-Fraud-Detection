# FraudGuard AI — True Streamlit / ML Integration

This version separates the trained ML model from the UI.

## Architecture

```text
loan_diversion_dataset_22f.csv
          |
          v
   train_model.py
          |
          v
model_artifact.joblib
          |
          v
      app.py
          |
          v
   Streamlit dashboard
```

The model training follows the supplied notebook:
- StandardScaler for numerical columns
- OneHotEncoder(handle_unknown="ignore") for categorical columns
- `mcc_mismatch_flag` passed through the ColumnTransformer
- RandomForestClassifier(class_weight="balanced", random_state=1)
- RandomizedSearchCV with the notebook's parameter distributions
- 80/20 stratified split with random_state=1

## 1. Train the model

Put the training CSV beside these files and run:

```bash
python train_model.py --data loan_diversion_dataset_22f.csv
```

This creates:

```text
model_artifact.joblib
```

## 2. Run Streamlit

```bash
streamlit run app.py
```

## 3. Deploy

Commit these files to GitHub:

```text
app.py
model_artifact.joblib
requirements.txt
README.md
```

Then deploy the repository on Streamlit Community Cloud.

Important: `model_artifact.joblib` is generated by the training step. Do not expect Streamlit to train the model every time the page opens.
